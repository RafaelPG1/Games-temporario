Como jogar

Vire duas cartas por vez e encontre todos os 10 pares de símbolos iguais, com o menor número de tentativas. Se as cartas forem diferentes, elas viram de volta: memorize onde cada símbolo está.

Pontuação

  • +100 a cada par encontrado
  • +25 por acerto seguido (acumula)
  • −10 a cada erro
